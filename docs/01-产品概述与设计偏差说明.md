# 01. 产品概述与设计偏差说明

> 本章定位:把"现在到底要做什么"以及"为什么和最早的设想不一样"一次说清楚,
> 后面所有具体方案都基于此。

---

## 1. 产品定位(沿用并强化)

> **"QuestGuild: Family Task RPG"** —— 用 RPG 公会冒险的壳,做家庭任务管理的核。

面向 **3-12 岁孩子的家庭**,主要解决"家长催、孩子拖"这个长期冲突。
把"写作业 / 练琴 / 收拾书包"这些日常任务,包装成父母发布的 Quest(任务),孩子作为 Adventurer 接取 → 提交证明 → 父母审核 → 拿到 XP → 升级 → 解锁现实特权。
关键差异化:

1. **孩子主动**:不是"家长追着催",而是"孩子在 Quest Board 抢着接";
2. **现实奖励绑定等级**:每升一级会解锁一个"现实特权"卡(决定周末活动、点菜权、晚睡 15 分钟等),让升级有现实意义;
3. **赛季剧情包装**:每个 Season(学期/假期)挂一个 Theme + narrative,任务标题/描述自动由 AI 包装,孩子能持续获得新故事。

## 2. 与原需求/原设计的关键差异(勘误表)

下表把从 `D:\workspaces\documents\生活online\` 那批老文档到当前方案的差异
明确化,以便后续所有人参考一致。**"现状"列即本轮新方案的取值。**

### 2.1 技术栈替换

| 维度 | 原方案 | 现状(v2) | 备注 |
|---|---|---|---|
| 后端语言 | Go 1.18+ | **Python 3.12 + FastAPI** | 异步 + 类型注解 + LLM 生态优势 |
| 后端框架 | Gin | FastAPI | 同步保留 OpenAPI/Swagger 能力 |
| ORM | GORM | SQLAlchemy 2.x async + Alembic | async 生态 |
| DB | MySQL 8.0+ | MySQL 8.0+ | 不变 |
| 缓存 | Redis(占位) | **未引入** | 时间币/赛季等都用 DB 即可,Sprint 评估需要时再上 Redis |
| 调度 | 无 | APScheduler(每日 0:05 时间币重置) | 已落地 |
| 对象存储 | 计划 OSS/COS | MinIO / 本地 storage 抽象 | 已落地,可平滑切到 OSS/S3 |
| 前端-管理端 | 微信小程序管理 | React 19 + Vite + Tailwind + `@google/genai` | 内部工具,Web 形态更高效 |
| 前端-家长端 | 微信小程序 | **Taro 4 (React) 一码多端(微信小程序 + H5)** | 兼顾微信生态 + 浏览器 |
| 前端-孩子端 | 微信小程序 | **Taro 4 (React) 一码多端(微信小程序 + H5)** | 同上 |
| 第三方 | 微信模板消息 | 微信登录 + LLM(任务/主题/审稿 AI) | 模板消息暂未启用 |

### 2.3 数值体系(关键修订)

| 项 | 原设计 | 现状(本轮 v2) |
|---|---|---|
| 升级公式 | 强调"指数增长",但未给出具体公式 | **采用指数公式** `xp_to_next(L) = round(BASE * (1.5 ** (L-1)))`, BASE=200(可调) |
| 经验值来源 | 单维:任务 × 星级 | **多维**:基础值 × 星级系数 × 时效系数 × 速度系数,详见 [04-数值系统](./04-数值系统.md) |
| 软上限 | "每日经验软上限" | **不设**——交给**时间币**做经济限速 |
| 任务押金 | 无 | **新增 TimeCoin 体系**:接任务扣 `time_deposit`,完成退还,放弃按规则惩罚 |
| 星级 | 1-5 星,5 星 1.5 倍 | 保留 5 星,系数微调(5/4/3/2/1 → 1.5/1.2/1.0/0.8/0.6) |

## 3. 本轮(v2.0)的目标

> 把当前后端 + Web 后台的 MVP 形态,**升级为"三端完整 P0 + P1"的可对外发布版本**。

1. **指数经验值公式落地**:把 `xp_service.xp_needed_for_level` 由 `level * 1000`(线性)
   改为指数曲线,补全回归测试。
2. **三端工程就绪**:`packages/client` 用 Taro 起出"家长端 + 孩子端"两个分包,
   全部对接后端真实 API(替换 `packages/admin` 当前的 mock)。
3. **P1 核心功能补足**:
   - 任务模板库(后端 + 家长端)
   - 隐藏任务(后端 + 家长端 + 孩子端)
   - 限时任务(补 deadline,孩子端超时自动 EXPIRED)
   - 家长数据看板(管理后台 + 家长端)
   - 存储清理策略(后端)
   - 新手适应期(孩子端 + 后端任务线配置)
   - 消息提醒(家长端 + 后端,基于微信模板消息 + 站内通知)
4. **文档基线化**:本文档集为后续一切实现/讨论的唯一基线。

详细分章见后续文档。
