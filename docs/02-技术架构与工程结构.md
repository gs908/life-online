## 3. 后端(server/)技术栈

| 类别 | 选型 | 备注 |
|---|---|---|
| 运行时 | Python 3.12 | `pyproject.toml` 已用 uv 管理 |
| Web 框架 | FastAPI 0.11x | 异步,自带 OpenAPI |
| ORM | SQLAlchemy 2.x async | 已落地 |
| 迁移 | Alembic | 当前 `versions/4bb73fc2e250_initial_schema.py` |
| 配置 | pydantic-settings + config.yaml | `app/config.py` |
| 鉴权 | JWT (access + refresh) | `app/common/security/jwt.py` |
| 对象存储 | 自研 `app/common/storage` 抽象 + MinIO 实现 | 可切 OSS/S3 |
| LLM | `app/common/llm` 抽象 + OpenAI 协议实现 | 已支持 Ark/Kimi/DeepSeek/OpenAI/Ollama |
| 调度 | APScheduler | `app/workers/scheduler.py` |
| 日志 | `app/common/logging.py` | JSON 结构化 |
| 依赖 | uv | 锁文件 `uv.lock` |
| 测试 | pytest + pytest-asyncio | 待补齐 |
| Lint | ruff + mypy | 待补齐 |

### 3.1 后端模块结构

```
server/app/
├── main.py                # FastAPI 实例 + lifespan

├── api/v1/                # REST 路由
│   ├── router.py          # 路由聚合
│   ├── health.py
│   ├── auth.py            # /sys/auth
│   ├── users.py           # /sys/accounts
│   ├── families.py        # /sys/families + /sys/invites
│   ├── seasons.py         # /scn/seasons
│   ├── tasks.py           # /scn/task-instances
│   ├── themes.py          # /scn/themes
│   ├── coins.py           # /scn/coins
│   ├── privileges.py      # /scn/privileges
│   ├── redemptions.py     # /scn/redemptions
│   ├── time_config.py     # /scn/time-configs
│   ├── uploads.py         # /scn/uploads
│   └── ai.py              # /scn/ai(LLM 包装)
├── common/
│   ├── db/                # engine / session / Base
│   ├── storage/           # 对象存储抽象
│   ├── llm/               # LLM 抽象
│   ├── security/          # JWT
```

## 6. 跨端协议与契约

### 6.1 API 风格

- 基础前缀: `/api/v1`
- 资源命名: `/sys/<身份类>`(系统级,如 `auth/users/families`),
  `/scn/<业务类>`(场景/业务级,如 `seasons/tasks/coins/privileges/...`)
- 统一响应: `{ "ok": true, "data": ... }` / `{ "ok": false, "error": { "code": "...", "message": "..." } }` — 已落地于 `app/schemas/common.py`
- 鉴权: `Authorization: Bearer <access>`,refresh 走 `/sys/auth/refresh`

### 6.2 错误码

由 `app/common/exceptions.py` 定义基础错误类型,FastAPI 全局 handler 统一转为标准响应。
本轮新增的 P1 模块也复用此机制,不要绕过。

### 6.3 跨端共享类型

- TS 类型不在仓库内强制共享(避免 TS ↔ Python 同步成本)。
- 改为:后端 OpenAPI 自动生成 → 家长/孩子端用 `openapi-typescript` 生成类型,或手写 DTO + 注释"对齐 OpenAPI"。
- `packages/utils`(若引入)只放纯函数,不放类型。

## 7. 部署 / 启动(本轮需补)

| 服务 | 本地 | 远期 |
|---|---|---|
| MySQL 8 | `docker compose up -d mysql` | RDS |
| MinIO | `docker compose up -d minio` | OSS/S3 |
| 后端 | `cd server && uv run python start.py` | Docker / k8s |
| 后台 | `pnpm --filter admin dev` | 静态文件部署 |
| 家长端 | `pnpm --filter parent dev:weapp` / `dev:h5` | 微信开发者工具 / H5 |
| 孩子端 | `pnpm --filter child dev:weapp` / `dev:h5` | 同上 |

> 本轮新增 `docker-compose.yml` 在仓库根,统一起 MySQL + MinIO。
