## 1. 一句话定位

**"QuestGuild: Family Task RPG"** —— 表面是 RPG 公会冒险, 内核是家庭任务管理。

- **家长**是 Guild Master(公会会长),负责发布任务、审核证据、签发奖励;
- **孩子**是 Adventurer(冒险者),在 Quest Board(任务大厅)里接取任务、上传证明、积累 XP 升级、解锁特权;
- **赛季**(Season)是时间维度的剧情包,每个赛季绑定一个 Theme(主题/画风)和一段 narrative context(剧情上下文),所有任务和特权的解锁都挂在赛季上下文中。

数值上保持**两套独立体系**:
- **XP / 等级**:长期成长,使用**指数曲线**控制升级节奏;
- **时间币 (TimeCoin)**:短期经济,作为任务押金控制刷任务、并产生行为约束(连续放弃惩罚)。

详细偏差说明与原设计对比见 [01-产品概述与设计偏差说明](./01-产品概述与设计偏差说明.md)。
