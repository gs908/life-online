# 05. 功能矩阵与端划分(P0 / P1 / P2)

> 本章定位:把 v2.0 要做的功能**逐项拆到端**。
> 原则:
> - **管理后台(`admin`)** 管"内容与运营"(模板库、隐藏任务投放、数据看板、通知设置);
> - **家长端(`parent`)** 管"日常管理"(创建任务、审核、查看孩子状态、收通知);
> - **孩子端(`child`)** 管"游戏化执行"(Quest Board、接任务、提交、看等级、领奖);
> - 同一功能**最多出现在两个端**,优先"管理后台 + 用户端"组合,避免三端重复。

---

## 1. 端的能力定位

| 端 | 谁能用 | 主要场景 | 不能做的事 |
|---|---|---|---|
| 管理后台(Admin) | 内部产品/运营 | 配置系统预置数据、查看全量指标、运营干预 | 不直接面对孩子(无孩子登录入口) |
| 家长端(Parent) | Guild Master(父母) | 微信扫码登录、创建任务、审核、看孩子、收通知 | 不编辑系统模板、不调整赛季默认参数(改后台) |
| 孩子端(Child) | Adventurer(孩子) | 看任务大厅、接任务、提交、看等级特权、领奖 | 不审核任务、不改设置 |

## 5. 端间共享与去重

> 同一份业务事实只在一处维护,其它端只读。

| 业务事实 | 唯一源 | 其它端如何访问 |
|---|---|---|
| 用户身份 | 后端 `sys_account` | 三端均通过 `/sys/auth/me` |
| 孩子档案(level/xp/coin) | 后端 `sys_child` | 家长端 / 孩子端读 `/sys/accounts/me` |
| 当前激活赛季 | 后端 `scn_season(is_active=true)` | 任意端 `/scn/seasons/active` |
| 当前主题 | `scn_season.theme_id` + `scn_theme_style` | 孩子端读,parent 在创建任务时选 |
| 通知 | 后端 `scn_notification` | 站内 + 微信 |
| 模板库 | `scn_task_template_library` | Admin 写,Parent 读 + 引用 |
| 数值公式 | `server/app/config.py` | 后端单点;前端只展示结果,不重复算 |

## 7. 关键 P1 的"端边界"注意事项

1. **隐藏任务** — 仅 Parent 投放,Child 端**禁止看到"隐藏任务存在"这个事实**,
   只能看到"刚解锁了一个新任务"弹窗。
2. **数据看板** — Parent 端看到自己家庭;Admin 端可跨家庭;Child 端**不**有看板。
3. **新手引导** — Child 端独享,Parent 端能看"孩子当前在第几步",不直接控制。
4. **模板库** — Admin 端可以"上下架系统预置";Parent 端浏览 + 应用 + 收藏;
   家庭自建模板 Admin 端**不**编辑。
5. **消息通知** — Parent/Child 都可关微信模板消息,但**不能关"任务提交"通知**
   (否则父母没法审核),可在 Admin 端调"通知必达列表"。
6. **赛季切换** — Parent 端可切;Admin 端可强制(用于紧急运营);
   Child 端只在打开 App 时被动拉取。
